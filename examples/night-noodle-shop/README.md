# 示例 · 深夜面馆

一条 22.6 秒的双人对话短片，从拆场到资产确认的完整实录。用来演示这套流水线在真实项目里长什么样，包括它卡住的地方。

## 这个例子能看出什么

**1. 拆场不是按叙事节拍拆的**

这条片子分两组生成：G1 是「问」，G2 是「答」。但场表里只有一场——因为空间没变、时间没跳、人物组合没变。

> 节拍属于分镜，场属于空间与时间。把「问/答」当两场，会多做一套场景资产。

**2. 反打视角里，让人物背对镜头**

`S1_reverse.png` 是反打：相机在女儿肩后，看向母亲和灶台。画面里的母亲**完全背对镜头**，看不到脸。

这不是构图偏好，是闸门逼出来的。前两版失败：

| 版本 | 结果 | 原因 |
|---|---|---|
| 第 1 版 | 置物架上冒出一只后厨大汤桶 | 没带道具资产当参考，模型自己给了一个 |
| 第 2 版 | 母亲变成另一个 60 多岁的人 | 没带人物资产当参考，只靠文字描述 |
| 第 3 版 | 通过 | 让她背对镜头，看不到脸，就不会错 |

**3. 容器的「结构可用性」比好看重要**

`O1_hero_rejected.png` 是被拦下的版本：桶口收窄成瓶形、盖子隆起成圆顶。视觉上像暖水瓶，看一眼就不对——因为这东西装不进也倒不出。

`O1_hero.png` 是改对之后的：直筒、口径等于底径、矮平盖、盖外径等于桶口。

模型的默认倾向是**收口**（收口看起来更精致），所以凡是有「口」的道具，必须主动写同径。

**4. 为什么不上 3D**

这条片子只有三个固定机位（过道侧中景、台面近景、母亲中近景），人也不走动。为三个机位各出一张 2D 静帧，比建 3D 便宜得多。

> 3D 的判据是「有没有 3 个以上机位 / 转身走动 / 明显透视变化」，不是「越高级越好」。

```
└── assets/

    ├── S1_reverse.png      场景反打（已确认）——母亲背对镜头
    ├── O1_hero.png         保温桶单品格（已确认）——直筒，口径=底径
    ├── O1_hero_rejected.png  同道具的反例：被闸门拦下的瓶形版本
    └── O1_scale.png        保温桶带手比例格——尺寸靠它才能验收
```

## 从资产表里能读到的东西

`资产表.md` 的第七节「进度与闸门」记录了当时的真实状态：道具全部通过、人物只过了一张、场景缺主视角。

那张表最有价值的一行是这段批注：

> **P2 是本次返工最该先做的东西。** 前几版母亲在近景里被画成 60 岁，就是因为没有一张确认过的 `P2_front` 当锚点，每个镜头都是从文字重新生成一次。

这条片子前后改了八轮，母亲的脸、道具的形态、取桶的空间关系都在反复漂。根因全是同一个：**没有确认过的资产锚点**。资产先行的全部意义就在这里。

## 复现这份资产表

```
1. 读剧本 → 写场表（本文第 1 点）
2. 按四类拆资产 → 填 assets/asset-registry.md
3. 逐项出定妆图 → 过三关（身份 / 比例 / 干净）
4. 过不了的标出来，不要带着缺陷往下走
5. 全过之后，才写分镜和提示词
```
