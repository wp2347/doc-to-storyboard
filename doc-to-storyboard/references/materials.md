# 元素与材质

提示词里最能拉开差距的不是形容词，是**具体的表面和具体的光**。这份文件解决两件事：元素卡怎么写，材质与光用什么词。

## 一、元素卡

三张卡：人物、场景、道具。写法一致：**名词 + 可见特征 + 状态**，不写评价。

### 人物卡

```
P1｜中年男性，四十五岁上下，短发略有花白，面容沉稳，鼻梁清晰，
眼角有细纹，深灰色羊毛西装外套内搭深色衬衫，未系领带。
```

要点：

- **年龄 + 性别 + 族裔** 必须给，这是稳定性的底座
- **脸**：写三个可辨认特征（鼻梁、眼型、脸型、皱纹位置），不要只写"面容俊朗"
- **发型**：长度 + 质感 + 是否打理。写"随性的低马尾配八字刘海"比"长发"稳定十倍
- **服装**：材质 + 颜色 + 穿法（敞开/扣上/挽袖/未系领带）。材质决定反光，反光决定质感
- **体态**：坐姿、肩线、手的位置
- 不写：性格、职业感、气质。这些无法被执行

### 场景卡

```
S1｜日式餐厅包间，木质格栅隔断，一盏低垂黄铜吊灯，
吊灯在桌面正上方形成集中光锥，背景虚焦，两侧墙面有暖色壁灯。
```

要点：**必须写清主光源在哪、朝哪打、光锥落在哪。** 光位不写死，跨镜就会换天光。

### 道具卡

```
O1｜两只无脚红酒杯，杯壁薄，杯中有红酒约三分之一，
液面在移动时轻微倾斜晃动。
```

要点：**写状态**。满/半/空、干净/有水渍/有指纹、完整/破损。状态就是剧情。

#### 道具的三件必写事项

道具是短片里最容易"凭空出现"和"尺寸失控"的东西。三件事写不清，成片一定出戏：

**1. 尺寸用身体参照，不要写数字了事**

模型对"大/小"没有绝对尺度，对人体才有。`直径 12 厘米` 它不认识，`桶口直径约等于一只成人手掌的宽度` 它认识。

| 写不动的 | 写得动的 |
|---|---|
| 保温桶不要太大 | 桶口直径约等于一只成人手掌的宽度，一只手能托住桶底并握住桶身 |
| 手机大小的盒子 | 一个成人手掌刚好能整个包住 |
| 一把长柄伞 | 立起来到人的腰高 |

**2. 入场：道具必须先存在，才能被使用**

道具在某个镜头里突然出现，观众会立刻察觉"这不是刚才那个空间"。两种入场法：

- **提前埋（首选）**：在前面的镜头里让它待在场景里，虚焦、不在焦点上、不抢视线。观众看见了但不注意，等它被拿起时就有出处。这也常常是最好的叙事——她早就准备好了。
- **给动作**：专门给一个"拿起 / 打开 / 从某处取出"的动作镜头，明说来源。

**禁止**：让道具在某个镜头里已经被人拿在手上，而此前从未出现过。

**3. 位移连续：道具的位置变化要有交代**

从台面 A 点到 B 点，中间要么有"推 / 拿 / 放"的动作，要么就不该动。上一镜它在手里、下一镜它在桌上，中间没有放下的动作，观众的直觉是"剪错了"。

写作时在道具卡里补一行 **入场位置**，并在分镜表里检查它每一镜在哪。

**4. 结构必须可用**

道具得先"能用"，再谈好看。写容器就写口径与桶身的关系，写抽屉就写它拉得开，写门就写它有开合空间。

实测：保温桶被画成桶口收窄、盖子隆起的瓶形——视觉上一眼不对，因为这东西装不进也倒不出。补上「直筒、桶口直径等于桶底直径、盖外径等于桶口」才立住。**模型的默认倾向是给一个"收口"的造型，因为收口看起来更精致**，你不写明同径，它就收。

#### 道具参考图：直接从成片里裁

文字描述锁不住道具外形——同一段描述，两次生成可以是两只完全不同的桶。**最可靠的办法是从已经生成好的画面里裁出道具特写，当参考图带进后续每一条生成。**

做法：从某条已完成的视频里取一帧道具清晰的画面 → 裁到只剩道具（不要带人脸和手）→ 作为参考图，并在提示词里写「图 N 为道具参考，外形、比例、提手与盖子以此为准」。

这条比写一百字外貌描述都准，而且零成本。

**但别裁得太满。** 参考图的构图会被搬进成片：裁到道具占满 90% 画面的那版，模型照着把道具放大，结果道具在镜头里撑满下半个画面、被画幅边缘切掉。正确做法是**保留一个比例参照物**——旁边站一只人手，或让道具只占参考图的一半宽度。这样模型拿到的不只是外形，还有"它有多大"。

一句更保险的写法：`图 N 为道具与比例参考，外形与它和成人手掌的尺寸关系以此为准`。

**先确认道具是什么，写到「识别特征」为止。**

只写类名，出图必然串味。而且写尺寸和颜色不够——真正决定观众认不认的是**它怎么被携带、怎么被使用**的那个部件。

| 容易混的一组 | 识别特征（写了才不会错） |
|---|---|
| **保温桶**（老式带饭桶，最典型） | 矮胖圆柱，口径≈桶高；**桶身侧面一个红色塑料横提手**（可翻转）；**桶身竖向波浪压筋**；**顶部叠层圆盖**（圆顶盖 + 底下盖环，盖心凹一圈） |
| 细高旋盖保温桶（商用） | 通体不锈钢细高筒；螺旋旋盖 + 盖顶小提环；桶身横向环纹 |
| 保温壶 / 热水瓶 | 有**杯盖**和**出水嘴**，盖能当杯子用 |
| 提锅 / 保温饭桶 | 矮胖圆柱；**顶部弓形提梁**；卡扣密封盖 |
| 后厨汤桶 | 深桶；只有桶身两侧小耳，没有提手 |

同一个道理适用于：饭盒 / 便当盒 / 提锅；手包 / 公文包 / 挎包；雨伞 / 阳伞；茶杯 / 酒杯 / 品鉴杯。**先写"提手长什么样"和"盖子是哪种"，再写尺寸和颜色。**

**实测教训（一个道具改了四轮）**：写「矮圆筒 + 卡扣盖 + 两侧提耳」出来是后厨汤桶；写「弓形提梁 + 竖压筋」出来是矮胖提锅；写「细高 + 旋盖 + 提环」出来是商用桶——都不是用户说的「保温桶」。

根因不是描述不够精确，是**术语没对齐就开始精确**。所以：**近义道具、地方叫法、行业俗称，先要用户给一张参考图**，比来回四轮文字便宜得多。拿到参考图后直接当道具参考图带进生成，一轮就能对。

如果拿不到图，至少先问一句："你说的 X，是带红提手那种，还是旋盖那种？"——一句话省三轮。

### 卡的反面与正面

| 反面 | 正面 |
|---|---|
| 一个中年男人，穿西装，很有气质 | 四十五岁上下亚裔男性，深灰羊毛西装外套内搭深色衬衫，未系领带，短发略有花白 |
| 一个温馨的餐厅 | 木质格栅隔断，黄铜吊灯低垂，光锥落在桌面中央，背景虚焦 |
| 一杯红酒 | 无脚红酒杯，杯壁薄，酒液约三分之一，液面微倾 |

## 二、材质词表

直接取用，按需组合。**同一画面里主材质不要超过三种**，多了会糊。

**织物**
羊毛呢的哑光起绒感｜粗针织的垂坠与孔洞｜亚麻的挺括褶皱｜真丝的流动高光｜法兰绒的绒毛边｜牛仔的斜纹与磨白｜羽绒的绗缝鼓包｜棉布的洗旧泛白

**皮革**
头层牛皮的细纹与折痕｜油蜡皮的光泽与深浅不匀｜麂皮的绒面吸光

**金属**
黄铜的暖反光与氧化斑｜不锈钢的冷硬高光｜做旧铝的哑光划痕｜铸铁的粗糙颗粒｜焊缝的鱼鳞纹｜铆钉的半球高光｜掉漆露出底层的分层｜警示条纹的风化剥落

**木与竹**
橡木的开放纹理｜旧漆面的龟裂｜格栅的条状阴影｜水曲柳的直纹｜竹编的交叉压痕

**石与陶瓷**
水磨石的骨料颗粒｜大理石的半透光｜粗陶的釉面不均｜青瓷的开片｜水泥的毛孔与色差

**玻璃**
厚玻璃杯的绿色切面｜酒液的挂杯｜窗玻璃的雨渍与反光｜磨砂玻璃的雾面透光

**墙面与地面**
乳胶漆的哑光｜微水泥的斑驳｜贴砖的勾缝与泛黄｜旧壁纸的翘边｜湿沥青的反光

**皮肤与人体**
鼻翼的油光｜眼角的细纹｜胡茬的青灰｜指节的泛红｜握紧时手背的肌腱｜喉结的起伏

**空气与介质**
光锥里的浮尘｜灶台的油烟｜雨后地面的薄水｜呼吸的白气｜香烟的蓝灰扩散

**食物**
酱汁的高光与黏稠｜米饭的颗粒感｜油光的半透｜菜肴边缘的干缩

## 三、光怎么写

光的四件事，缺一件画面就会变成"通用打光"：

| 属性 | 选项 | 写进提示词的例子 |
|---|---|---|
| 方向 | 正面 / 侧 / 侧逆 / 逆 / 顶 / 底 / 低角度侧光 | 主光从画面右侧 45° 侧逆打来 |
| 软硬 | 硬（阴影边界锐利）/ 软（渐变过渡）/ 混合 | 吊灯是硬光，桌面边缘的阴影边界清晰 |
| 色温 | 2700K 钨丝暖黄 / 4000K 中性 / 5600K 日光冷白 | 钨丝灯的暖黄，背景壁灯偏橙 |
| 衰减 | 迅速跌落（光锥集中）/ 均匀铺开（环境光） | 光锥外迅速衰减成暗部 |

**实用句式**：「一盏低垂的黄铜吊灯在餐桌上方投下集中的光锥，光锥外迅速衰减」——一句里包含方向（顶）、软硬（硬）、色温（暖）、衰减（迅速）。这比"氛围温馨"有用一百倍。

## 四、表情、视线与结构

这三样是首帧最容易翻车、又最容易被漏写的地方。

### 表情

**不要只写「悲伤」「克制」这类结论词，写面部在做什么。**

| 结论词 | 换成可执行的描述 |
|---|---|
| 克制 | 嘴角平直，下颌放松，眼睑略垂 |
| 隐忍 | 咬住下唇，鼻翼轻微张开，眉心有一道竖纹 |
| 释然 | 嘴角松开但不上去，呼气，肩膀落下 |
| 疲惫 | 眼下有青灰，眼神不聚焦，眨眼变慢 |
| 强撑 | 嘴角向上但眼睛没有跟着笑 |

情绪是反向的戏（该冷的地方要暖、该笑的地方不能笑），**必须加否定句兜底**：不微笑、不露齿、嘴角不上扬。生成模型的默认倾向是给一张讨喜的脸，你不挡它就会加。

### 视线

视线方向决定这场戏的关系，写清楚落点：

- 「视线落在对面人的眼睛上」——对峙
- 「视线落在桌面的桶上」——回避
- 「视线越过对方看向门」——想走
- 「视线不看向镜头」——这句几乎每张首帧都要写，模型很爱让主角看镜头

### 结构

有开合、连接、承托关系的道具，**必须写清结构关系**，否则模型会画出悬空、穿模、分离。

| 道具 | 要写清 |
|---|---|
| 带盖的容器 | 桶盖严丝合缝扣在桶身上，不悬空、不分离 |
| 杯子与手 | 手指包住杯壁，杯底落在掌心 |
| 门与框 | 门扇贴合门框，不穿透 |
| 桌上的餐具 | 每件都实际接触桌面，不漂浮 |

## 五、禁用词与替换表

这些词出现在提示词里等于没写：

| 禁用 | 替换成 |
|---|---|
| 电影感 | 35mm 胶片电影感，低对比度，暖黄偏绿调色 |
| 高级感 | 低饱和、单一材质体系、大留白 |
| 质感很好 | 具体材质：黄铜的氧化斑、羊毛呢的起绒感 |
| 氛围感 | 光源位置 + 色温 + 空气中的介质（浮尘/油烟/薄雾） |
| 唯美 | 柔焦晕光 + 浅景深 + 逆光轮廓 |
| 真实 | 保留皮肤纹理与瑕疵，环境不做无意义的收拾 |
| 有故事感 | 人物视线不看向镜头，画面里有未被解释的物件 |
| 运镜丰富 | 一个镜头一种运动，写清是哪种 |
| 情绪饱满 | 写明表演提示：压得很低、抿住嘴、喉部起伏 |

**自查方法**：把提示词里所有形容词划掉，如果剩下的信息还能画出画面，就合格。
