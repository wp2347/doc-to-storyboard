# 资产流水线

资产先行的全部要点：怎么拆、怎么产、怎么验收、改了什么要重跑什么。

## 一、拆幕成场，再拆资产

### 1.1 场表

先落一张场表，它决定了后面所有资产的范围。

| 场号 | 地点 | 时间 | 在场人物 | 时长 | 一句话内容 | 需要的资产 |
|---|---|---|---|---|---|---|
| 场 1 | 面馆前厅 | 夜 | P1 P2 | 12s | 女儿告别，母亲没接话 | S1 O1 |
| 场 2 | 同上（时间未跳） | 夜 | P1 P2 | 10s | 母亲取出保温桶 | S1 O1 |

**换场的三个条件**（任一满足就换场）：空间变了、时间跳了、人物组合变了。

一场 = 一条时间轴 = 一套场景资产。同一空间如果时间没跳，可以合并成一场、共用 S 资产。

### 1.2 四类资产怎么拆

**人物 `P`** — 每个有台词或会露正脸的人都要一套。

| 视角 | 用途 | 必须性 |
|---|---|---|
| 正面中景 | 主参考图，锁脸 | 必须 |
| 侧面 | 锁侧脸轮廓与鼻梁，跨镜转头时用 | 必须 |
| 关键表情 1–2 张 | 情绪戏的表演基准 | 有情绪戏才做 |

只有手入画、不露脸的人物，不做整套，只做一张**手部特写**归到 `D` 类。

**场景 `S`** — 每个空间至少两张。

| 视角 | 用途 | 必须性 |
|---|---|---|
| 主视角 | 叙事常用机位，锁布景、光位、色调 | 必须 |
| 反打视角 | 从对面机位拍回去，锁空间的另一面 | **必须** |

反打是这条流水线里最容易被省、也最容易出事的资产。不做反打，同一场戏的正反打会变成两个不同的屋子——观众一眼看出拼接。

**道具 `O`** — 按叙事权重分三级。

| 级别 | 判据 | 做法 |
|---|---|---|
| 一级 | 被人物拿起、推动、传递、注视 | 单品格 + 带手比例格，两张都要 |
| 二级 | 只在背景重复出现，没人碰 | 并进场景资产，不单独做 |
| 三级 | 一次性出现 | 不单独做，写进场景描述 |

**细节 `D`** — 只在会跨镜复现时做。判据：这个东西在三个以上镜头里能被看见。典型的是墙面材质、地面水渍、灯光位置、蒸汽/烟雾。

### 1.3 拆多细

参考量级：**15 秒单场对话戏 4–6 项资产；60 秒多场戏 12–20 项**。

超过 25 项说明拆过细，把二级以下道具并进场景。少于 4 项说明拆不够，多半会漏掉反打或道具比例格。

## 二、2D 资产生产

### 2.1 命名规范

```
ASSET-ID_视角.png

P1_front.png      P1_side.png     P1_expr_tense.png
S1_main.png       S1_reverse.png
O1_hero.png       O1_scale.png
D1_wall.png
```

编号一旦分配不再复用。废弃的资产改名加 `_deprecated`，不要删——后面要对比"当时用的是哪一版"。

### 2.2 每类的提示词骨架

**人物 · 正面**

```
[风格卡质感块，五项齐全]，横版 16:9，中景，正面平视。
【主体】<P 卡全文：年龄、面部三特征、发型、服装、体态>
【姿态与表情】站定，双手自然垂在身侧或放在身前，视线看向镜头方向但不直视，嘴角平直，不微笑。
【背景】简洁、虚化，不抢主体；保留一张与场景同色调的背景做参考。
【负面约束】无多余人物；无文字字幕水印；不微笑不露齿；手指完整；服装与描述一致。
```

**人物 · 侧面**

同上，改「中景，正侧面 90 度，可见完整侧脸轮廓与鼻梁线条」，其余照抄——**描述段一个字都不改**，只改机位。

**场景 · 主视角**

```
[风格卡质感块]，横版 16:9，<机位高度与焦段>。
【空间】<S 卡全文：空间性质、尺寸感、墙面地面材质、家具陈设>
【光位】主光在哪、朝哪打、光锥落在哪、软硬与色温、衰减方式。必须写死。
【画面边界】哪个方向是墙、哪个方向是门或通道——这一条决定后面能不能同一空间换机位。
【负面约束】无人物（或只留必要人物剪影）；无文字字幕水印。
```

**场景 · 反打视角**

以主视角为参照，写明「这是同一空间从对面机位拍回的视角，主光位置与色温保持一致，只是相机转了 180 度」。**不写这句，出来的会是另一个房间。**

**场景里出现人物时，有三条硬规矩**——否则同一场戏会冒出第三个人：

1. **首选不带人**：把人清空，只留空间。场景资产的作用是锁布景和光位，不是锁表演
2. **必须带人时，让人物背对或虚焦**：只留背影、肩背、手臂，不露正脸。反正场景资产的正脸没有任何信息量
3. **非要露正脸，就必须把 P 资产当参考图一起传**，并在提示词里写「图 N 为人物参考」。只靠文字描述，出来一定是另一个更老/更年轻的人

实测：反打视角里写「四十八岁亚裔女性在擦台面」，出来是另一个六十多岁的人；改成「完全背对镜头看不到脸」，一次就过。

**道具 · 单品格**

```
[风格卡质感块]，横版 16:9，中景。
【主体】<O 卡全文：类别名称 + 三个身份特征 + 材质 + 结构>
【摆放】放在台面上，正侧 3/4 角度，完整入画、不被裁切。
【负面约束】无人物；无文字字幕水印；结构完整不穿模、不悬空。
```

**道具 · 带手比例格**

同上，加「一只成年人的手从画面右侧伸入，握住/扶住道具，手与道具的比例清楚可见」。
**这一张不做，尺寸就只能靠猜**——实测一个道具做了四轮，最后是靠"旁边有只手"才把大小定下来。

**细节**

```
[风格卡质感块]，横版 16:9，特写。
【主体】<D 卡：什么材质、什么状态、什么纹理>
【光】主光角度与强度，能看清纹理的高光与阴影。
```

### 2.3 验收三关

| 关 | 具体查什么 | 不过的典型表现 |
|---|---|---|
| 身份关 | 年龄、脸、发型、服装；道具的类别与三个身份特征 | 人物老十岁；保温桶变成汤桶；提手位置不对 |
| 比例关 | 用人手对照尺寸；**结构是否合理且可用** | 道具占满半个画面；被画幅边缘裁切；**容器口径窄于桶身、取不出东西** |
| 干净关 | 有无多余人物、烧制字幕、穿模、悬空 | 两侧各出现一个人影；画面烧进台词字幕；桶盖悬空分离 |

**结构可用性单列一条，因为它最容易被"好看"盖过去。** 容器的口径不能小于桶身，否则饭菜倒不出来；抽屉要能拉开，门要有开合空间；提手要能握住，扣件要能开合。实测一只保温桶被画成桶口收窄、盖子隆起的瓶形，视觉上像暖水瓶——观众一眼觉得不对，就是因为这东西没法用。

三关全过才在资产表里标 `已确认`。**没过就重出，不要凑合**——一张资产图错了，引用它的每一条镜头都会错。

## 三、3D 资产（按需）

### 3.1 先判断值不值

3D 的产出不是模型文件，是**从任意机位渲染出来的静帧**。只有"需要多个机位"时它才划算。

| 上 3D | 不上 3D |
|---|---|
| 同一空间 3 个以上机位 | 固定机位对话戏 |
| 人物转身、走动、穿过空间 | 单人特写 |
| 环绕、推轨、明显透视变化 | 镜头不动 |
| 同一道具要从多个角度反复出现 | 道具只出现一两次 |

**如果分镜只有 2–3 个固定机位，直接为每个机位各出一张 2D 静帧，比建 3D 便宜得多。**

### 3.2 流程

1. **备料**：拿已确认的 2D 主图做输入。人物用正面 + 侧面两张做 multi-view，几何更准；道单单张就够
2. **生成**：image-to-3D，输出 OBJ + GLB（要材质就开 PBR）。单个模型通常 1–5 分钟
3. **查几何**：比例对不对、结构是否连通（提手有没有接在桶身上、盖子有没有悬空）、有没有破面
4. **摆机位**：照分镜表的机位逐个摆相机，渲染静帧，命名 `P1_cam03.png`
5. **验收**：把 3D 渲染的静帧与对应机位下的 2D 定妆图并排看，构图、光位、比例应该基本对得上。差太多说明 3D 建歪了，**回退用 2D**，不要硬修
6. **入库**：静帧写进资产表，状态标 `已确认（3D）`

### 3.3 没有 3D 工具时

降级方案，按优先级：

1. 为每个机位单独出一张 2D 静帧（最实用，成本最低）
2. 用正面/侧面/背面/俯视四视角拼 multi-view 参考，喂给支持多图的模型
3. 只保留一个主视角，靠景别变化（中景/近景/特写）代替机位变化

## 四、资产表与状态机

### 4.1 状态流转

```
待生成 → 已生成待确认 → 已确认 → 已弃用
                ↑            │
                └── 重出 ────┘
```

只有 `已确认` 的资产能被镜头引用。`已生成待确认` 的不算。

### 4.2 失效传播

**资产一改，引用它的镜头全部作废。** 这是资产先行的代价，也是它管用的原因。

为了能一眼看到影响面，资产表里必须有一列 **被引用的镜头**：

| 编号 | 名称 | 类型 | 状态 | 文件 | 被引用的镜头 |
|---|---|---|---|---|---|
| P2 | 母亲 | 人物 | 已确认 | P2_front.png / P2_side.png | S01 S03 S04 S05 S06 S07 |
| O1 | 保温桶 | 道具 | 已确认 | O1_hero.png / O1_scale.png | S05 S06 S07 S08 |
| S1 | 面馆前厅 | 场景 | 已确认 | S1_main.png / S1_reverse.png | S01–S08 |

改 P2 的脸 → 上表里 S01 S03 S04 S05 S06 S07 全部重跑。
改 O1 的外形 → S05–S08 重跑。
改 S1 的光位 → 整场重跑。

**改动前先看这一列，改之前就知道要重跑几条。**

### 4.3 镜头侧的引用检查

每条视频提示词的开头必须有一行资产声明：

```
图 1 为人物参考（P2），图 2 为空间与光位参考（S1），图 3 为道具与比例参考（O1）。
```

**没有这行的提示词，视为未接资产，不许提交。** 有这行但引用的资产状态不是 `已确认`，同样不许提交。

## 五、常见崩坏与对策

| 症状 | 根因 | 对策 |
|---|---|---|
| 配角在每个镜头里长得不一样 | 只给主角做了资产 | 每个露正脸的人都要一套，配角也一样 |
| 同一空间正反打像两个屋子 | 没做反打视角 | 每场必须出 `S_main` + `S_reverse` |
| 道具每镜大小都不同 | 只有单品格，没有比例格 | 补 `O_scale`，让手入画 |
| 改了资产但成片没变 | 镜头的参考图没换，或旧图缓存没清 | 改完资产立刻更新资产表的文件路径，重跑时确认引用的是新文件 |
| 改一版资产要重跑十条镜头 | 拆得太细，资产耦合过高 | 把不叙事的东西并进场景，减少一级道具数量 |
| 3D 建完反而更差 | 2D 输入本身有缺陷，或机位与分镜不符 | 先确认 2D 三关全过；3D 只是几何发生器，不能修 2D 的错 |
| 资产越做越多停不下来 | 没有按音量级拆 | 超过 25 项就合并二级以下资产 |
