# 风格卡库

一张风格卡 = 一组可以逐字抄进提示词的视觉参数。**卡定下来，全案视觉描述以它为准，不改味、不混卡。**

## 一、字段定义

每张卡只描述这九项，因为只有这九项能被生成工具执行：

| 字段 | 写什么 | 反面例子 |
|---|---|---|
| 介质与机身 | 胶片/数码/录像带/手绘；具体机型或型号气质 | 「电影感」 |
| 镜头 | 焦段与光学特征（35mm 广角畸变、85mm 压缩、变形宽银幕横向拉丝） | 「好看的镜头」 |
| 光线 | 主光方向 + 软硬 + 色温 + 有无实用光源 | 「打光很讲究」 |
| 调色 | 低/高对比、饱和度、偏色方向（暖黄偏绿、青蓝、褪色） | 「高级色调」 |
| 景深与焦点 | 浅/深、焦点落在哪、有无柔焦晕光 | 「虚化很好看」 |
| 材质偏好 | 这张卡偏爱的表面质感（织物毛边、做旧金属、水磨石） | 「很有质感」 |
| 运镜倾向 | 一镜一种运动：推进 / 拉远 / 横摇 / 跟随 / 固定 | 「运镜丰富」 |
| 构图倾向 | 对称/偏侧/大留白/手持晃动/固定机位 | 「构图精美」 |
| 禁项 | 这张卡绝不能出现的东西 | — |

## 二、十张内置卡

### 1. `jp-nostalgia` 日式怀旧胶片

- **介质**：35mm 胶片电影感，Arri Alexa Mini 质感
- **镜头**：35–50mm，轻微桶形畸变，允许少量光学瑕疵
- **光线**：低垂实用光源（吊灯、壁灯、窗光），光锥集中、边缘迅速衰减
- **调色**：低对比度、低饱和度、暖黄偏绿
- **景深**：浅景深 + 柔焦晕光，高光轻微溢出
- **材质**：木质格栅、亚麻、粗陶、旧漆面、水磨石
- **运镜**：极缓慢推进或固定，几乎不晃
- **构图**：过肩中景、横跨空间的双人
- **禁项**：高饱和、冷白 LED、锐利 HDR、现代玻璃幕墙
- **适合**：家庭、告别、旧关系、克制情绪

### 2. `hk-neon` 港产霓虹犯罪

- **介质**：数码高感光，颗粒明显，夜景
- **镜头**：24–35mm 广角，贴近人物，轻微变形
- **光线**：霓虹作主光，红绿蓝混色，湿地面反光，硬光
- **调色**：高对比、饱和偏品红与青绿
- **景深**：中等偏浅，背景霓虹化成色块
- **材质**：湿沥青、铁闸、亚克力灯箱、贴满招贴的墙
- **运镜**：手持跟随、横摇扫过招牌
- **构图**：偏侧构图、大量前景遮挡
- **禁项**：柔光、日式低饱和、干净背景
- **适合**：悬疑、追逐、灰色交易、夜行动物

### 3. `cn-street-realism` 中式市井烟火写实

- **介质**：数码纪实，轻微噪点，不修饰
- **镜头**：28–40mm，平视或略低
- **光线**：白炽灯管、灶火、招牌灯，混合色温不做统一
- **调色**：中等对比，饱和略降，暖调里带一点青
- **景深**：中等，环境要看得清
- **材质**：油烟、塑料凳、不锈钢台面、贴瓷砖的墙、蒸汽
- **运镜**：固定为主，偶有跟随
- **构图**：拥挤、多层信息、人物被环境包围
- **禁项**：极简、大留白、精致摆盘
- **适合**：小人物、地方故事、生活切片、方言戏

### 4. `nordic-minimal` 北欧极简生活

- **介质**：中画幅数码，极致干净
- **镜头**：50–85mm，无畸变
- **光线**：北向大面积窗光，柔、冷、均匀，无硬阴影
- **调色**：低饱和、低对比、灰白米色系
- **景深**：中浅，背景是干净的几何面
- **材质**：原木、羊毛、哑光陶、棉麻、微水泥
- **运镜**：固定机位或极慢横移
- **构图**：大留白、对称、人物占画面小比例
- **禁项**：杂物、暖黄、霓虹、手手持晃动
- **适合**：家居、生活方式广告、独处、克制叙事

### 5. `urban-beauty-ad` 都市类型广告

- **介质**：高规格数码，皮肤质感保留但修饰过
- **镜头**：85mm 人像压缩 + 微距特写交替
- **光线**：柔光箱主光 + 轮廓光勾边，眼神光必给
- **调色**：干净通透，肤色准确，背景略降饱和
- **景深**：极浅，背景彻底化开
- **材质**：皮肤的高光、针织的细绒、玻璃的通透、金属的冷反光
- **运镜**：缓推、环绕、升格特写
- **构图**：正中、对称、产品与人同框时产品永远在焦内
- **禁项**：脏背景、硬阴影、杂乱色块
- **适合**：美妆、护肤、饮品、人物向品牌片

### 6. `new-chinese-ink` 新中式水墨

- **介质**：绢本/宣纸质感的数字合成，允许墨的渗化
- **镜头**：长焦压缩，空间层次靠虚实而非透视
- **光线**：方向性弱的散射光，靠墨的浓淡造明暗
- **调色**：近乎单色，只在关键处点一抹朱红或石青
- **景深**：大面积虚化，实体边缘柔化
- **材质**：生宣的纤维、墨的干湿浓淡、绢的经纬、青瓷的釉
- **运镜**：极缓横移或静止，靠画面内的动（烟、水、衣袂）
- **构图**：大留白，主体偏侧，留出题款位置
- **禁项**：写实皮肤细节、现代材质、硬边阴影
- **适合**：文化题材、品牌调性片、诗词意象、节气

### 7. `cyber-rain` 赛博雨夜

- **介质**：数码，暗部有彩色噪点
- **镜头**：21–35mm，强烈透视，仰角
- **光线**：多光源混色（青、洋红、钠黄），雨幕把光打成体积光
- **调色**：高对比，暗部压青，高光偏洋红
- **景深**：浅，光斑成块
- **材质**：积水、雾气、镀膜玻璃、全息屏、湿金属
- **运镜**：缓慢升摇、环绕、贴地推进
- **构图**：垂直线条密布、人物被巨构压住
- **禁项**：暖黄主调、自然光、干净空气
- **适合**：科幻、未来都市、孤独感、技术焦虑

### 8. `vhs-90s` 90 年代家用录像带

- **介质**：VHS 家用摄像机，扫描线、色度溢出、时间码压角
- **镜头**：固定变焦镜头，变焦略迟钝，对焦有呼吸
- **光线**：机顶灯或室内日光灯，硬、平、色温偏绿
- **调色**：低宽容度，高光死白、暗部发灰，整体褪色
- **景深**：深景深，全都清楚
- **材质**：廉价家具、化纤窗帘、塑料玩具、老电视
- **运镜**：手持晃动、突然拉近、拍摄者入画
- **构图**：不讲究，越随意越真
- **禁项**：稳定器、浅景深、调色精致
- **适合**：回忆、伪纪录片、年代感、家庭影像

### 9. `mecha-industrial` 战损工业钢

- **介质**：高规格数码，参考《环太平洋》危险流浪者的实拍质感
- **镜头**：35mm 低角度仰拍，强透视放大体量
- **光线**：逆光/侧逆光勾出轮廓，环境光脏、有雾
- **调色**：去饱和，钢灰 + 锈红 + 警示黄，暗部偏冷
- **景深**：中等，机身细节要清楚
- **材质**：焊缝、铆钉、掉漆、油污、警示条纹、风化标识、雨渍。**杜绝光滑抛光金属**
- **运镜**：低角度环绕、慢速推近，节奏必须慢，凸显重量
- **构图**：机身在画面里永远显得过大、被裁切
- **禁项**：塑料感、镜面反射、卡通比例、快切
- **适合**：机甲、工业产品、力量感题材

### 10. `cel-anime` 日式赛璐璐动画

- **介质**：2D 赛璐璐上色，线条统一粗细
- **镜头**：动画常用透视，背景为手绘水彩
- **光线**：简化为两到三档明暗，高光成块
- **调色**：中高饱和，色彩分区明确
- **景深**：无真实景深，靠层次和空气透视
- **材质**：平涂色块、网点、手绘背景的笔触
- **运镜**：平移背景（PAN）、突然的推镜、定格
- **构图**：人物居中或三分，背景信息量大
- **禁项**：写实皮肤纹理、真实镜头光晕、3D 渲染感
- **适合**：青春、幻想、情绪外化、类型化角色

## 三、从参考图提卡

用户给参考图或参考片时，**不要直接形容"像什么"，要拆字段**。

### 提卡四步

1. **先看五件事**：色温偏冷还是暖、对比高还是低、饱和高还是低、介质是数码/胶片/录像带/手绘、光源硬还是软。这五项定了，卡的骨架就有了。
2. **补细节**：焦段（看透视强弱）、景深（背景糊到什么程度）、主要材质（画面里反复出现的表面）、运镜（只有参考片才判断得出）。
3. **写成字段**，逐项填满九栏。填不出的项写「（参考图未体现，建议固定为 X）」，不要留空。
4. **请用户确认**，确认后才写提示词。

### 两条铁律

- **参考图必须带进后续生成请求**，不能只留文字描述。文字带不住视觉细节，尤其带不住人物的脸。
- 一张参考图不足以定义风格时，请用户补 2–3 张同风格素材；不要靠一张图推全部字段。

## 四、混卡规则

- **介质与调色只能有一个来源。** 混了就是四不像。
- 可以借用另一张卡的**运镜倾向**或**构图倾向**，但要在卡里写明「运镜借自 X 卡」。
- 用户要求混卡时，说清哪部分来自哪张，让用户确认，不要默默混。

## 五、没有合适的卡时

不要硬套。基于用户的描述新建一张卡，字段照九栏填满，命名 `custom-<关键词>`，并告知用户这张卡是新建的、后续可复用。
