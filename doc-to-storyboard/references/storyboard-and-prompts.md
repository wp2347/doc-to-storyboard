# 剧本、分镜与提示词配方

## 一、剧本格式

只写能拍出来的东西。心理活动转成外部动作，否则删掉。

```
场 1｜内景 · 日式餐厅包间 · 夜

一张四人桌只坐两人。吊灯低垂，光锥落在桌面中央。
男人（45 上下）放下筷子，抬眼看对面。
女人（27、28）握着酒杯，指节泛白。

男人　（语速慢，声音低）
　　　这件事，我其实早就知道了。

（停顿。他只折了一下餐巾，放在桌沿。）

女人　（视线垂下，又抬起）
　　　那你为什么一直不说？
```

规则：

- **场次头**写：内外景 / 地点 / 时间
- **动作行**独立成段，不让动作和台词挤在同一行
- **台词**前面标说话人，括号里写表演提示（语速、音量、情绪），不要写"悲伤地说"这类抽象词，写"压得很低""说完抿住嘴"
- **停顿单独标出来**——沉默是表演，也是算时长的一部分

## 二、时长算法与切点

### 台词时长

**中文口语 4–5 字/秒**，取 4.5。加上标点停顿：

| 标点 | 停顿 |
|---|---|
| 逗号 | 0.2s |
| 句号 | 0.4s |
| 省略号 | 0.6s |
| 破折号 | 0.4s |

计算式：`字数 ÷ 4.5 + 停顿合计`

例：「这件事，我其实早就知道了。」 → 11 字 ÷ 4.5 ≈ 2.44s + 一个逗号 0.2s + 句号 0.4s ≈ **3.0s**

### 切点规则

1. **切点落在台词收尾之后 ≥0.3s**。低于 0.3s，下一镜的台词会顶上上一句的尾音，成片里听起来像抢话。
2. 动作镜（无台词）不少于 1.5s，否则观众看不清发生了什么。
3. 每镜上限 6s。更长的内容拆成两镜，不要用一镜硬扛——镜头久了会显得呆。
4. **每组时长 = 末镜时间码结束 − 本组首镜时间码开始**（即各镜之和 + 组内间隔 0.2s×（镜数−1））。不要凭感觉报一个整数，也不要漏掉间隔——这条最容易算错。

### 时长必须取整

视频接口的秒数字段只收整数。`7.8`、`4.5` 这类值会在**提交阶段**就被拒，请求根本进不了生成队列——报错长这样：

```
cannot unmarshal number 7.8 into Go struct field ... of type int32
```

所以：

1. **在分镜阶段就把每组算成整秒**，向上取整。别等提交时才改，改时长会连带改掉切点，整组时间码要重排。
2. 取整后的多出来那零点几秒，用来**加长落点镜的尾部静止**，不要平摊给其他镜。结尾多停半秒，观感上是稳，不是拖。
3. 取整前后的差异要写进交付说明。原来 12.5 秒的片子最终是 13 秒，这件事必须让用户知道，不能默默变成 13 秒。

### 报时长时必须报实数

`00:04.500` 这种时间码，不要写「大约 4 秒半」。时间码写错，整组切点全错。

## 三、分镜表

### 列定义

| 列 | 内容 |
|---|---|
| 镜号 | `S01` `S02`… 全片连续编号 |
| 分组 | `G1` `G2`… 同组镜头合并成一条视频 |
| 时间码 | `00:00.000–00:03.200` |
| 时长 | 秒，一位小数 |
| 景别 | 大特写/特写/近景/中近景/中景/中全/全景/远景 |
| 运镜 | **一种**：固定 / 慢推 / 慢拉 / 横摇 / 跟随 / 环绕 / 升降 / 手持 |
| 画面内容 | 谁在哪、在做什么、环境里有什么 |
| 台词与动作 | 台词原文 + 说完的收势动作 |
| 声音 | 动作音、环境音、音乐提示 |
| 首帧 | 该镜静帧的编号（如 `IMG-02`），或「接 S01 末帧」 |

### 分组规则

- **同组 = 同空间 + 同时间 + 连续动作 + 同一人物组合。** 四项有一项不同就换组。
- **每组 2–4 镜。** 超过 4 镜必须拆组——挤进去的后果是台词全堆在开头几秒，切点全部失效。
- 每组必须有一镜是**落点镜**：整组结束停在哪，由它决定。
- 一组只承载一个情绪节拍。组与组之间才是转折。

### 分组示例

```
G1（S01–S03，共 12.4s）男人开口 → 女人反问 → 男人解释并递杯
G2（S04–S05，共 6.8s）女人僵住 → 碰杯落定
```

## 四、文生图首帧提示词配方

首帧图有两个用途：当参考图锚定人物长相，当单镜模式的首帧。**必须单独生成，不要从视频里截。**

```
[质感块，一句连写]
照片级写实电影剧照，<介质与机身>，<焦段>，<光线>，<调色>，<景深>，横版 16:9，<景别>。

【构图】相机位置与高度、取景方式、左右各是谁、正在发生什么、哪些部位必须完整可见。

【人物左】
<元素卡 P1 全文，逐字照抄>

【人物右】
<元素卡 P2 全文，逐字照抄>

【环境与道具】
<元素卡 S1/O1 全文>，桌面上的东西逐一列出。

【负面约束】
不微笑 / 视线不看向镜头 / 画面中无任何文字与字幕 / <道具>结构完整不分离 / 画面中只有 <N> 个人。
```

**四条要点**

1. 质感块必须来自风格卡，五项齐全（介质/镜头/光线/调色/景深）
2. 人物卡照抄，不要在提示词里临时补形容词——补一次，后面每条都要重新补
3. 明确点出「哪些部位必须完整可见」（手、脸、道具），不然模型最容易在手上翻车
4. **【负面约束】是必填段，不是可选项**。写法见本文第六节；漏掉这一段，首帧大概率带上你不想要的微笑、视线和字幕，而这些会被原样搬进视频

## 五、分组多分镜视频提示词配方

一组一条。**镜头之间用 [Shot n] 分段，时间码写在段首。**

```
[Shot 1] <景别>。<环境：空间、光源位置、材质、景深>。相机以<一种运动>。<人物描述段（缩略版：年龄+发型+服装）>，<动作>，说道：<d>[Chinese] 台词原文。</d> <说完的收势动作>。
[Shot 2] 在 00:04.500，镜头切至<景别变化>，相机<保持静止/继续运动>。<人物描述段>，<动作>。说道：<d>[Chinese] 台词原文。</d> <收势动作>。
[Shot 3] 在 00:08.000，镜头切至<景别>，相机以<运动>。<人物 A 描述> <动作>。<人物 B 描述> <动作>。相机在最后两秒停止移动，<两人的坐姿、手部位置、道具位置、光锥落点>逐步收窄差异，最终在第 <N> 秒落定于 <Picture 1> 建立的画面。
overall_soundscape: <环境底噪 + 动作音，逐个列出：什么声音、什么时候出现>
non_diegetic_music: <配乐如何进场、如何变化、在哪里收束>
```

**七条要点**

1. **时间码必须和分镜表的切点一致**，不要两边各写一套
2. **一个 [Shot] 只写一种运镜**，写两种以上画面会乱
3. **台词必须用 `<d>[Chinese] ……</d>`** 包起来，语言标签不能省、不能改。一行一句，长台词拆成两句，不要堆在一行
4. **每句台词后面跟一个收势动作**（闭嘴、折餐巾、抿唇）。没有收势，模型会让嘴一直动
5. **最后一镜必须有"落定句"**：写明最后两秒停住、要收窄哪几项差异、落在第几秒。不写这句，结尾一定飘
6. `overall_soundscape` 和 `non_diegetic_music` 是两条独立的行，别混写。逐个列声音，不写"氛围感音效"
7. **动作必须写明施动者，禁止被动句**

### 被动句会让道具自己动

写「那只保温桶**被**向右推过台面」——出片是桶自己滑过去，母亲的手垂在身侧，没人碰它。这不是模型出错，是字面执行：被动句里没有施动者，它就生成了一个无人推动的位移。

| 写不动的（被动） | 写得动的（主动） |
|---|---|
| 保温桶被推过台面 | 她的右手掌按在桶身朝她那一侧的圆弧面上，手指张开贴住金属，然后手臂往前一送，桶底跟着她的手一起滑出去 |
| 门被打开 | 她的左手握住门把手，手腕一转，门扇向内让开一条缝 |
| 杯子被递到面前 | 她的拇指扣住杯壁，把小杯往对方那边推了半掌 |

三条配套写法：

- **写清接触点**：手按在哪儿、贴住什么、握着哪一部分。没有接触点，模型就敢让物件悬空移动
- **写清跟随关系**："桶底跟着她的手一起滑出去"——比"把桶推出去"更能锁住两者同动
- **写清接触何时结束**："桶停住之后，她的手才从桶身上松开"。不写，模型可能整段都黏在桶上

## 六、负面约束

生成模型默认往「好看」的方向走：人物微笑、光打得漂亮、画面干净、结构无损。剧本要的常常正相反。**你不挡，它就会加。**

### 6.1 两类写法，正向优先

| | 写法 | 作用 |
|---|---|---|
| 正向（首选） | 嘴角平直，下颌放松，视线落在桶身上 | 给出要什么，模型才有落点 |
| 否定（兜底） | 不微笑，不露齿，不看向镜头 | 挡住最常见的那几种错 |

**先写正向，再补否定。** 只写否定，模型知道不要什么、却不知道要什么，容易换成另一个错；只写正向，模型可能顺手又把习惯性的微笑加回来。两句一起写才稳。

### 6.2 必查的六类禁项

每条首帧提示词都过一遍，哪类有风险就写哪类：

| 类型 | 什么时候必须写 | 句式 |
|---|---|---|
| 表情 | 情绪克制、悲伤、对峙 | 不微笑，不露齿，嘴角不上扬 |
| 视线 | 人物不该看镜头 | 视线不看向镜头，只看向画面左侧的母亲 |
| 字幕水印 | 任何情况都写 | 画面中无任何文字、字幕、水印 |
| 结构 | 有开合、连接、承托关系的道具 | 桶盖严丝合缝扣在桶身上，不悬空、不分离 |
| 多余人物 | 双人戏、独处戏 | 画面中只有两个人，背景不出现清晰的第三个人 |
| 手部 | 手在画面里且是重点 | 双手五指完整、关节自然，不出现多余手指 |

### 6.3 别把不想看见的东西逐一点名

「没有面粉、没有面团、没有面盆」这种否定列举，模型经常读成「这里可以有面粉、面团、面盆」。实测：提示词写了「台面上没有面粉」，出图的台面上反而撒了一层白色粉末，把「和面」的联想坐实了。

**正确做法：只说这里有什么。** 用「台面干净，只放着一块折叠的白抹布」替代「没有面粉、没有面团」。`只有 X` 比 `没有 Y` 稳。

判断标准：负面约束里只要出现**具体名词**，就改成正面句；只有抽象行为（不微笑、不看向镜头、不露齿）无法正写时，才保留否定式。

### 6.4 一条铁律：缺陷修在静帧

**参考图会把首帧的姿态、表情、结构整条搬进视频，视频提示词盖不过它。**

实测过的例子：首帧里母亲在笑，视频提示词明确写「低头、没有抬眼、咬住下唇」，成片里她依然在笑；首帧里桶盖悬空分离，视频里它继续悬空；首帧里女儿站着面向镜头，视频里她还是站着面向镜头。

所以：**静帧不过三关（人物、姿态、负面）就不许跑视频。** 一张图的成本远低于一条视频，卡在静帧上是省钱，不是拖延。

### 6.5 风格卡的禁项要落进提示词

卡里的「禁项」不是写给人看的注释，是必须进每条提示词的句子。`jp-nostalgia` 禁高饱和与冷白 LED，提示词里就得出现「低饱和、暖黄偏绿、不使用冷白光」。卡上写了、提示词没写，等于没写。

## 七、单镜视频提示词配方

一镜一条时用。核心差异：**必须交代首帧和末帧**，因为镜头之间没有模型帮你连贯。

```
<景别>，<相机运动>。<环境：空间、光源、材质、景深>。
首帧：<这一帧画面的精确状态，逐项写：人物姿势、手在哪、道具在哪、光锥落点>。
过程：<谁做了什么，动作的起手 → 中段 → 收尾>。台词：<d>[Chinese] 台词。</d>
末帧：<这一帧的状态，要能直接当下一镜的首帧用>。
overall_soundscape: <…>
```

### 首尾帧锚定法

- **本镜首帧 = 上一镜末帧**：把上一镜的末帧导出成图，作为本镜的参考图/首帧输入。这样坐姿、手位、道具位置能接上。
- **本镜首帧 = 静帧图**：用文生图单独生成该镜的首帧，作为参考图。
- **末帧必须写清楚**，否则下一镜没法接。

### 什么时候该用单镜

| 用多分镜 | 用单镜 |
|---|---|
| 同空间连续对话 | 多场景、多空间 |
| 情绪推进靠表演连贯 | 动作、特技、产品特写 |
| 需要整体色调统一 | 某一镜要反复精修 |
| 时长紧、镜数少 | 镜数多、每镜内容复杂 |

## 八、一致性维护

跨条一致性只有两个抓手：**固定文字段** 和 **参考图**。两个都要用。

### 固定文字段（元素卡编号）

| 编号 | 内容 | 用法 |
|---|---|---|
| `P1` `P2`… | 人物卡：年龄、面部特征、发型、服装、体态 | 提示词里写 `(P1)`，正文照抄全文 |
| `S1` `S2`… | 场景卡：空间、光源位置、材质、色调 | 同上 |
| `O1` `O2`… | 道具卡：形状、材质、状态（满/空、完整/破损） | 同上 |

**同一段文字在整份策划包里出现多次时，必须逐字相同。** 改一个字就是换了一个人。

### 参考图

- 首帧图生成后，**立刻**作为后续每条视频的参考图，不要只用文字描述代替
- 多条视频之间人物会漂，这是当前技术上限，**要如实告知用户**，不要承诺跨条完全一致
- 减少漂移的实际做法：镜头越近越容易露馅，把中近景集中在前半段，远景放在后面

## 九、跨组连贯

分组生成之后把几条拼成一条，最容易在接缝处"跳"。这不是生成质量问题，是**规划时没管接缝**。

### 9.1 四个断层

| 断层 | 现象 | 成因 |
|---|---|---|
| 声音 | 切点处底噪突然换了一个房间 | 每组独立生成，各带一套环境声。实测两条视频的底噪 RMS 可以差 20dB |
| 景别 | 近景接近景，人物整个换掉 | 只排了组内景别，没看跨组衔接 |
| 动势 | 两头都静止，像两段胶片硬粘 | 每组都"起幅静止、收幅静止" |
| 空间 | 观众丢掉两人相对的位置 | 组与组之间没有共享空间的画面 |

### 9.2 规划阶段必须定的四件事

1. **底噪同源**：整片只设计一条房间底噪，写进每组 `overall_soundscape` 的首句，**措辞逐字相同**。这是唯一能让接缝消失的根子办法。
2. **配乐跨组规划**：`non_diegetic_music` 按整片时间轴写进入点和收束点，不要每组各写一套——否则音乐会跟着切点断。
3. **景别交替**：相邻两组的接缝处，前一组收在中景/全景，后一组起于近景，或反过来。**禁止近景接近景**，那是观众最容易察觉"换了个人"的位置。
4. **留过渡镜**：组与组之间规划一个 0.8–1.5s 的中性镜头（空镜、手部、道具、蒸汽），单独生成一条。这是最便宜的缝合剂，也是唯一能在视觉上把两个空间缝起来的素材。

### 9.3 后期能救的（不重跑）

| 手法 | 做法 | 效果 |
|---|---|---|
| **J-cut** | 后一组的台词/环境声提前 0.3–0.5s 进，画面仍按原切点切 | 最有效，观众先闻其声再见其人 |
| **L-cut** | 前一组的环境声延续到后一组开头 0.3–0.5s | 次有效，把接缝从听觉上抹平 |
| **电平匹配** | 测两组底噪 RMS，给低的那条补增益 | 消除几十 dB 的落差感 |

测底噪的方法：取两条视频里各自最安静的一段（0.5s 以上无台词的区间），算 RMS 对比。差距超过 6dB 就必须补。

**同场对话不要用溶接。** 溶接的语义是"时间过去了"，用在连续对话上会让观众以为跳了时间。

### 9.4 道具的连续性

道具是跨组断裂最常见的地方，因为每组独立生成时它`不存在于另一组的画面里`。三个必查项：

1. **它属于这个空间吗**——如果只在后一组出现，前一组必须在背景里埋下它（虚焦、角落、不在焦点上）。埋不住就得给它一个"取出"的动作。
2. **尺寸对得上人吗**——尺寸必须用身体参照写（手掌宽度、一握、腰高），数字和"不要太大"都无效。详见 `materials.md` 道具卡一节。
3. **位置变化有交代吗**——从手里到台面、从 A 点到 B 点，中间必须有推/放/拿的动作镜，否则观众读作剪辑错误。

**组与组之间检查道具，比检查人脸更容易发现问题。** 因为人脸漂移是渐进的，道具凭空出现是一眼可见的。
