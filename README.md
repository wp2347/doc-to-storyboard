# doc-to-storyboard · 文档转短片（资产先行）

把一段文字、小说、剧本或故事大纲，做成一条**前后一致**的 AI 短片。

核心主张只有一句：**一致性不靠提示词反复描述，靠资产**。人物、场景、道具、细节先各自变成一张固定的图，所有镜头都去引用这些图——而不是每写一个镜头就重新生成一次外观。

## 为什么是资产先行

同一个道具，写两遍文字描述，出来是两件东西；同一张脸，写五遍，会有五个年龄。**文字锁不住外观，图片才锁得住。**

所以顺序是固定的：**先资产，后镜头**。反过来做（先写分镜再补资产）等于每镜各生成一次，一致性只能靠运气。

## 流水线

```
0 拆幕成场  →  1 建资产表  →  2 生产 2D 资产  →  3 2D 闸门
                                                    ↓
   6 拼接连贯  ←  5 按资产生成视频  ←  4 3D 资产（按需）
```

| 阶段 | 产出 | 关键点 |
|---|---|---|
| 0 拆幕成场 | 场表 | 空间变、时间跳、人物组合变，任一即换场 |
| 1 建资产表 | 四类资产的清单 | 人物 / 场景 / 道具 / 细节，各有必须项 |
| 2 产 2D 资产 | 定妆图 | 人物正面+侧面、场景主视角+反打、道具单品格+带手比例格 |
| 3 2D 闸门 | 已确认的资产 | 身份关 / 比例关 / 干净关，三关全过 |
| 4 3D（按需） | 多机位静帧 | 3D 不是交付物，是多机位静帧的发生器 |
| 5 按资产生片 | 视频 | 每条提示词按固定顺序引用资产 |
| 6 拼接连贯 | 成片 | J-cut / L-cut / 电平匹配 |

## 三条最容易被忽略的规矩

**场景必须做反打视角。** 不做，同一场戏的正反打会变成两个不同的屋子，观众一眼看出拼接。

**道具必须有带手比例格。** 只有单品格，尺寸就全靠猜。一张有手入画的图，比一百字描写都准。

**场景资产里出现人物时，让人物背对或虚焦。** 只靠文字描述「四十八岁女性在擦台面」，出来一定是另一个更老的人；要么别写人，要么把人物资产当参考图一起传。

## 十二条硬规则（摘要）

1. 资产先于镜头——没有确认的资产，不写镜头提示词
2. 资产编号即身份证——提示词必须写明引用了哪些编号
3. 资产一改，引用它的镜头全部作废
4. 人物描述段逐字复用
5. 台词用 `<d>[Chinese] 台词。</d>` 包起来
6. 切点落在台词收尾之后 ≥0.3s
7. 一组不超过 4 镜
8. 时长必须是整数秒
9. 不写"电影感""高级感"这类无法执行的空词
10. 负面约束必须显式写——不笑、不看镜头、不要字幕
11. **动作必须写明施动者，禁止被动句**——写「桶被推过台面」出来就是桶自己滑过去
12. 静帧不过关不跑视频

## 安装

这是一个 WorkBuddy / Claude 技能包，放进用户级技能目录即可全局生效：

```bash
git clone https://github.com/<owner>/<repo>.git
cp -R <repo>/doc-to-storyboard ~/.workbuddy/skills/
```

装好后，说「把这段文字做成短片」「按剧本拆场景和分镜」「建人物场景道具的固定资产」，技能就会被触发。

## 风格卡

内置 10 张，每张是一组可以直接抄进提示词的视觉参数（介质、镜头、光线、调色、景深、材质、运镜、构图、禁项）：

日式怀旧胶片 · 港产霓虹 · 中式市井写实 · 北欧极简 · 都市美妆广告 · 新中式水墨 · 赛博雨夜 · 90s 家用录像带 · 战损工业钢 · 日式赛璐璐

也可以给参考图，现场提取成一张卡。

## 这套规则是怎么来的

不是坐在屋里想的，是一条 22 秒的对话短片迭代了八轮之后，把每次翻车的原因固化成规则：

| 翻车 | 固化成的规则 |
|---|---|
| 母亲在近景里老十岁 | 人物必须有正面定妆图；没有锚点，每镜都会重新变一次 |
| 道具形态反复错四轮 | 近义道具先要一张参考图，别用文字反复试 |
| 保温桶被画成瓶形、取不出饭 | 道具的**结构必须可用**：口径不得小于桶身 |
| 保温桶自己滑向女儿 | **禁止被动句**，动作必须写明施动者与接触点 |
| 正反打像两个屋子 | 场景必须做反打视角 |
| 接缝处底噪跳 20dB | 底噪同源 + 电平匹配 + J-cut |
| 台词全挤在前七秒 | 切点必须落在台词收尾之后 ≥0.3s |
